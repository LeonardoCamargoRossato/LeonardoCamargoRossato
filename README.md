- **[MetCompB](https://github.com/LeonardoCamargoRossato/MetCompB)** — Python/Jupyter teaching and coursework notebooks covering numerical integration, epidemiological models, mechanics, stochastic systems and computational physics.
- **[University Engineering & Scientific Computing Archive](https://github.com/LeonardoCamargoRossato/Code_Courses_I-ve_takenAt_Universities)** — coursework in algorithms, scientific computing, electronics, numerical modeling and systems engineering.
